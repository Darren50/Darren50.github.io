# darren50.github.io

Personal site, built with Jekyll and hosted on GitHub Pages.

## Writing a blog post

1. Add a file to `_posts/` named `YYYY-MM-DD-title.md` (copy the front matter from an existing post).
2. Write in Markdown. Put images in `images/` and embed with `![alt](/images/file.png)`.
3. Commit and push; the site rebuilds in about a minute.

## Editing pages

- Home and the "Now" section: `index.md`
- About and achievements: `about.md`
- Projects: `work.md` and `work/`
- Nav and links: `_config.yml`
- Styles: `assets/css/style.css`
